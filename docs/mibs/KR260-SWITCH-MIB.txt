kr260Switch MODULE-IDENTITY
    LAST-UPDATED "202609210000Z"
    ORGANIZATION "Open Ethernet Switch project"
    CONTACT-INFO "https://github.com/GhlHub/open_ethernet_switch"
    DESCRIPTION
        "Read-only statistics for the KR260 R5 switch. Enterprise 32473
         is the RFC 5612 example number, used by agreement for this lab.
         Replace it with an assigned PEN before deployment. Counters are
         processor-accumulated totals since R5 restart; retrieval does not
         clear them. A walk spans multiple collection intervals. Check
         collection health and sensor validity before interpreting values."
    REVISION "202609210000Z"
    DESCRIPTION "Initial lab implementation."
    ::= { enterprises 32473 1 }
